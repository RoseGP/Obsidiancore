What changed in the meeting screen

Every earlier feature still works. Each one now sits either in the toolbar or in the More menu.

Always visible

  • Microphone and camera, red when off
  • Screen share, indigo while sharing
  • Participants and Chat, with count badges
  • More, with a red dot while recording
  • Leave, which also offers End meeting for everyone

Moved into More

  • Reactions
  • Meet & Greet, Transcript and CRM records panels
  • Invite people, copy invite link, copy meeting ID
  • Record, pause or resume, stop & save to Vault
  • Pause video stream, grid or speaker layout, full screen
  • Audio & video settings, return to dashboard

Phones and tablets

Buttons shrink and drop their labels. More opens as a sheet from the bottom. Side panels slide over the video and start closed below desktop width.

Bug fixed along the way

The Transcript panel and the Settings audio tab used two icons that were never imported, so opening either one crashed the meeting screen. Both now open normally.

Local GBP

To turn it on

  1. In Google Cloud, request Business Profile API access for your project. Google must approve it.
  2. Enable the Account Management, Business Information, Performance and My Business (v4) APIs.
  3. Add the scope business.manage to the OAuth consent screen.
  4. Create a Web OAuth client with redirect URI https://<your-domain>/api/local-seo/callback.
  5. Set the server variables on the right, then redeploy.

Server variables

  • GOOGLE_CLIENT_ID
  • GOOGLE_CLIENT_SECRET
  • APP_URL
  • SOCIAL_ACCOUNTS_ENCRYPTION_KEY
  • SOCIAL_ACCOUNTS_STORE=firestore
  • GEMINI_API_KEY (optional, for AI drafts)

Full guide: docs/local-seo/README.md
